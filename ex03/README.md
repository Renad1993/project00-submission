# Git and GitHub Project

## Why Git Makes Development Easier
Git makes development easier by using version control to save code and keep track of changes. developer can review previous versions and recover earlier work if there is any mistake.


Git keeps a history of changes through commits. Each commit records a specific change with message, making it easier to 
understand how the project developed over time.

Git helps team members collaborate by allowing multiple developers to work on the same project, share their changes, andcombine their work efficiently.
